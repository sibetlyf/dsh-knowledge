# 知识库 2.15.11

## 更新

- **早晨卡片悬浮 + 拖动**：卡片固定在视口中悬浮，不挤压欢迎页布局；拖动标题栏即可移动。
- **位置持久化**：拖动后的位置保存在本机 `localStorage`，刷新/重开欢迎页仍停留在原处。
- **边界约束**：拖动和窗口缩放时自动限制在视口内，不会跑出屏幕。
- **复位**：双击标题栏恢复默认「鲸鱼上方」位置，并清除保存的位置。
- 拖动手柄有抓取光标；关闭按钮不会触发拖动。

## 安装

```bash
dsh plugin --profile web add "github:sibetlyf/dsh-knowledge#v2.15.11"
```
