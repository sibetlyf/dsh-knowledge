# 知识库 2.15.2

## 更新

- **零操作对话召回**：没有手动召回挂载的会话会自动检索所有生效知识库，知识直接进入对话上下文；不需要先打开管理台或挂载。
- **二级目录**：自动整理会按 `一级/二级` 创建笔记目录；知识提取的新分组最多使用 `一级 · 二级` 两级名称。
- **目录与数据库一致**：知识文档按知识库名称和分组层级落盘，例如 `默认知识库/项目规范/部署/文档标题--id.md`；旧版 `base-<id>` 目录首次同步时自动迁移。
- **目录操作**：分组变更会同步移动磁盘目录；目录名经过安全清理但保留数据库中的中文、空格与层级名称。

## 安装

```bash
dsh plugin --profile web add "github:sibetlyf/dsh-knowledge#v2.15.2"
```

安装或更新后重启对应的 DSH Profile。
