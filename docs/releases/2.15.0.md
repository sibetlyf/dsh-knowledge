# 知识库 2.15.0

## 更新

- **任务文件自动归档（默认开启）**：每轮对话结束收集任务涉及的所有文件——`deliverables/presented`、所有工具参数中的路径（读取/写入/转换）、shell 命令路径与 workspace-changes 变更、用户 `@` 引用、上传附件——归档副本并纳入知识库，全程无需确认或审批。默认归档所有格式（`artifactArchiveExtensions: ['*']`），可配置收窄。
- **可写知识库自动补齐（默认开启）**：项目没有任何可写挂载时，自动把内置「默认知识库」以 `direct`（可配置为 `audit`）挂载到项目，不再出现“未挂载可写知识库”而无法写入；已有可写挂载、被显式关闭或设为仅召回的默认挂载保持原样。
- 归档副本按 SHA-256 内容寻址保存在知识库数据库相邻的 `artifacts/`；相同内容只存一份，内容变化时保留旧版本字节，源文件删除后仍可回溯。**具体文件保存在归档文件夹，数据库只保存链接、元数据与关键词**（默认 `artifactArchiveStoreContent: false`，不复制正文）；抽取文字用于生成关键词，开启该配置后才写入数据库正文。
- 新增配置 `artifactArchiveStoreContent`（默认 false）：仅保存文件链接、元数据、关键词与 `read` 读取提示；设为 true 时保留原来的正文入库行为。
- 每个文件对应一篇知识文档（`制品 · <相对路径>`，上传附件为 `制品 · 用户上传/<文件名>`，类型 `fact`），按文件类别归入 `制品 · 文档 / 表格 / 演示 / 图片 / 压缩包 / 音视频 / 代码 / 其他` 栏目；内容变化时原地更新并形成新版本，自动进入全文索引、检索与自动召回。
- **自动分类与新建栏目**：对话知识提取优先复用已有文档分组；现有已挂载知识库都不适合时，模型可请求一个全新的知识栏目（知识库），插件复用同名栏目或自动创建、挂载并直接写入，每轮最多一个，避免知识库爆炸。
- **取消人工审核**：新增后台自动批准器，周期性批准非冲突的待审核候选；笔记整理草案在 `noteOrganizeAutoApprove` 开启时直接落盘。真实冲突与凭据类内容仍保留安全拦截。
- 源码文件（代码类）会归档并参与双向链接，但不写入工作日报素材，避免日报被代码文件淹没。
- **制品文件浏览**：管理台新增「制品文件」页面，支持图片/PDF/文本/音视频预览、任意格式下载，并可一键打开对应知识文档进行编辑、调整分组或跨库移动；归档副本保持不可变。
- **默认数据目录不再写入 C 盘**：Windows 上优先使用插件所在非系统盘（例如 `G:\dsh-knowledge`），也可用 `DSH_KNOWLEDGE_HOME` 覆盖；首次启动会把旧 `C:\Users\<用户>\.dsh\knowledge` 的知识库、归档文件、连接配置与日报数据库复制到新目录（旧目录保留为备份）。
- **全量双向链接**：每篇知识文档自动显示「关联文档 / 反向链接」，按共同标签、同一分组与标题主题计算同库关联；只读/定稿文档的预览中，正文里的 `[[文档标题]]` 渲染为可点击链接并在目标文档显示反向链接，点击即可跳转。链接读取时实时计算，不写入正文、不产生额外版本；非空知识库中的每篇文档至少保留一个关联入口。
- **思维链接图**：管理台新增「思维链接」页，整库文档以动态力导向图展示；节点按分组着色、按链接数放大，边区分引用/标签/分组/主题，支持拖动、缩放、悬停高亮、点击打开文档与导出 PNG；文档底部「双向链接」面板可直接进入该库图谱。
- **界面布局优化**：整体字号提升（正文、导航、知识目录与工具栏），主内容区更宽；知识目录不再永久占据第三列，改为可滑出的抽屉，默认让文档区域占满宽度；主导航去掉冗余序号，层级更清爽。
- **PDF 论文自动整理**：识别论文并提取标题、摘要、关键词、年份、arXiv/DOI 与类别；首次出现论文时只创建一个「论文库」，按 `论文 · <类别>` 分组，摘要与关键词写入数据库并立即索引；非论文 PDF 留在制品库。
- **谨慎自动新建知识库**：对话提取每天最多自动新建 3 个知识库（`autoCreateKnowledgeBasesMaxPerDay`，可设 0 只复用），每轮最多一个、同名复用；论文只建一个论文库，不按单篇论文建库。
- **选择文件夹导入**：管理台「制品文件 → 导入文件夹」支持逐级浏览本机目录；递归扫描后自动归档、分类、论文识别、建立链接与索引，默认最多 800 个文件并跳过依赖/版本库/构建目录，文件多时后台继续。
- **插件联动契约**：宿主提供 `dshKnowledge` 服务（`ingestRecord`、`ingestFiles`、`search`、`listBases`、`introduceBase`），并广播 `knowledge/write`；未来会议、记忆等插件可按可选依赖接入。
- **减少重复操作**：再次进入「知识文档」自动恢复上次打开的文档，没有历史时打开最近更新的一篇；编辑既有文档停止输入约 1.4 秒后自动保存，状态栏显示“自动保存中…/已自动保存”，保存按钮保留为手动兜底。
- **对话中引入知识库**：输入框键入 `@` 后可从「引入知识库」分组选择任意生效知识库；发送时自动创建仅召回的会话挂载，自动召回、`knowledge_search` 与 `knowledge_read` 立即使用该库，且不会向该库回写对话内容。
- **后台运行可视化**：顶栏右侧常驻后台状态卡，每 3 秒显示自动归档进度（文件数/当前文件）、知识回写排队与处理数量、工作日报整理状态，完成后 12 秒提示归档结果；空闲时提示“后台自动整理”，可点击跳到制品文件、回写任务或工作日报。
- **知识库更新触发自动工作日报**：对话知识回写与制品归档完成后，自动把写入记录为当天日报素材，按 8 秒防抖在后台调用模型刷新当天日报；生成期间新增素材会自动继续整理，管理台手工编辑也会被后台巡检纳入。首次使用自动为该项目开启采集与每日生成，手工编辑过的日报不会被覆盖；远程模式经上传队列由中央生成。新增 `worklogAutoUpdateEnabled` 开关。
- 用户上传是明确输入，归档不受扩展名白名单限制（仍受单文件大小上限与排除模式约束）；上传内容按附件标识去重，重复上传不会重复建文档。
- 首次归档时自动创建 `制品归档` 知识库，并以仅召回（`writeMode: none`）方式挂载到当前项目；已有挂载设置不会被覆盖，知识库被人工归档后停止自动归档。
- 新增本地文本抽取：PDF 复用内置解析器，Word/PowerPoint/Excel 与 ODF 从容器 XML 抽取可见文字（含 Word 页眉页脚与脚注、演示文稿逐页、表格按行转 TSV），图片与其他二进制保留元数据。
- 新增只读制品接口 `GET /knowledge-control/v1/artifacts` 与 `GET /knowledge-control/v1/artifacts/<id>`，与其他管理接口同样要求同源管理台请求头。
- 新增配置：`artifactArchiveEnabled`、`artifactArchiveBaseName`、`artifactArchivePath`、`artifactArchiveExtensions`、`artifactArchiveExclude`、`artifactArchiveMaxFileBytes`、`artifactArchiveMaxChars`、`artifactArchiveStoreContent`、`artifactArchivePaperEnabled`、`artifactArchivePaperBaseName`、`artifactArchiveMaxEntries`、`artifactArchiveAutoMount`、`autoWritableMountEnabled`、`autoWritableMountWriteMode`、`autoCreateKnowledgeBases`、`autoCreateKnowledgeBasesMaxPerDay`、`autoApprovePendingEnabled`、`autoApprovePendingIntervalMinutes`、`noteOrganizeAutoApprove`、`worklogAutoUpdateEnabled`。
- 默认排除 `node_modules`、`.git`、`.dsh`、`.env`、私钥、SQLite 数据库等路径，文件正文超长时截断。

## 兼容

- 运行环境不变：DeepSeek Harness **0.2.1-rc.2**，Node.js `^22.19.0 || >=24.0.0`。
- 不修改 DSH Agent Loop，不新增模型调用；归档与知识写入在 `agent/turn-stopping` 之后后台串行执行，不阻塞对话。
- 远程知识库模式下归档与自动挂载需要 `write` 权限；没有权限时只记录日志，不影响对话与其他回写。

## 验证与升级

- 单元与集成测试覆盖：任务文件采集（present 声明、工具读写路径、shell 路径、workspace 变更、`@` 引用、上传附件、轮次边界、全格式与按类别分组）、文本/PDF/Office/ODF 抽取、内容去重与原地版本更新、索引持久化、排除与大小上限、源文件删除后的副本读取、无上传服务时跳过、可写挂载自动补齐与显式覆盖保护、自动新建/复用知识栏目、自动批准非冲突候选并保留安全拦截、知识库写入事件与日报素材记录/防抖刷新/手工日报保护、双向链接计算与跳转接口、知识链接图节点/边/分组与截断、后台状态接口的鉴权与计数，以及 `agent/turn-stopping` 到知识库的完整自动流程（不产生待审候选）。
- 升级无需迁移：首次归档时自动创建文件知识库与项目挂载；已有项目在下一轮第一个模型步骤自动补齐可写挂载。已配置的插件字段保持不变，新字段使用默认值。

安装：`dsh plugin --profile web add @lemoncat7/dsh-knowledge@2.15.0`。升级后请重启实际使用的 Profile。

详细配置与限制见 [制品自动归档](../artifacts.md)。
