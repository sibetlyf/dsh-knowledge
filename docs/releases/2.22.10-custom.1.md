# 2.22.10-custom.1 — 合并上游 2.22.10，保留本地增强

## 上游

- 合并 `lemoncat7/dsh-knowledge` `main` 的 2.22.10：统一知识工具入口、工作日历、目标追踪、iCloud 同步、空闲读写与远端补同。
- 工作记录、知识目录、笔记工作区与远程管理台以 2.22.10 为基线；没有直接改写 DSH Agent Loop。

## 保留并重新接线的本地增强

- **早晨卡片**：欢迎页鲸鱼标上方的浮动卡片；日报、今日待办、会议助手状态；拖拽与双击复位。
- **每日待办 / 简报**：`todos` 表、工作/生活分类、跨天承接；`/todos`、`/brief` 与日报生成素材共用同一数据。
- **周报 / 月报**：`/period` 按日报与待办聚合；工作记录页提供生成入口。
- **腾讯文档**：设置页保存 `space_secret`；知识目录导入、文档发布到腾讯文档。
- **知识文档只读分享**：`/knowledge-shares` admin API 创建随机令牌；公开 `/shared-knowledge/:token` 页面无需 DSH 或 Bearer Token；`/raw` 可下载 Markdown；撤销立即失效。

## 边界

- 公开分享页仍由 DSH WebServer 提供，必须让接收方能访问该地址；反向代理若加登录保护，需把 `/knowledge-local/v1/shared-knowledge/` 作为公开路径。
- 腾讯文档需要对应的桥接工具已安装；没有工具时状态页会明确报错，不影响其他知识功能。
- 上游测试中的 Windows 临时目录清理 `EPERM` 为本机环境问题；功能断言通过。
