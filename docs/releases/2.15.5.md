# 知识库 2.15.5

## 更新

- **每日待办**：工作日报页新增「每日待办」，支持工作/生活分类、添加、勾选完成、删除，以及「顺延昨日未完成」。
- **每日简报**：根据昨日日报和当天待办生成「昨日回顾 / 今日待办」，可展开查看并复制 Markdown；不额外调用模型。
- **日报整合待办**：生成日报时会把当天待办作为输入，在日报中增加「今日待办」一节，保留工作/生活分组、完成状态与承接日期，不会把待办写成已完成。
- 待办持久化在工作记录数据库中，按日期保存；视图不会因切换日期丢失。

## 安装

```bash
dsh plugin --profile web add "github:sibetlyf/dsh-knowledge#v2.15.5"
```
