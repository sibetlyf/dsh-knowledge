# 知识库 2.15.3

## 更新

- **腾讯文档导入**：知识目录顶部输入 `docs.qq.com` 链接，读取云端正文并创建本地知识文档，保留来源链接。
- **本地发布到腾讯文档**：知识文档工具栏「发布到腾讯文档」，将 Markdown 发布为腾讯文档智能文档（MDX），返回云端链接。
- **复用官方 MCP**：读写都通过 dsh-tencent-docs-bridge 已挂载的 `mcp__tencent-docs__*` 工具，本地不保存腾讯 `space_secret`。
- **未登录提示**：bridge 未连接时，导入/发布会提示先运行 `tdoc-auth login`，不会静默失败。

## 安装

```bash
dsh plugin --profile web add "github:sibetlyf/dsh-knowledge#v2.15.3"
```
