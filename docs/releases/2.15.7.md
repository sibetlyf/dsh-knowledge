# 知识库 2.15.7

## 更新

- **早晨卡片移到欢迎页**：卡片现在出现在无会话欢迎页鲸鱼 logo 上方，而不是工作日报页顶部；工作日报页恢复为纯日报视图。
- **早晨卡片内容**：今日待办（工作/生活）、完成数、直接勾选，以及快捷添加一条待办；每分钟自动刷新。
- **会议助手联动**：卡片通过 DSH 公共工具接口读取 `meeting_agent_status` / `meeting_status`，显示「会议助手正在听」「会议助手 · 标题」「会议助手已就绪」或「会议助手未连接」，不导入会议插件内部模块。
- 卡片读取失败时不影响欢迎页与对话，只显示一行提示。

## 安装

```bash
dsh plugin --profile web add "github:sibetlyf/dsh-knowledge#v2.15.7"
```
