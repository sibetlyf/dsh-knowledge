# 知识库 2.15.4

## 更新

- **腾讯文档手动 token**：管理台「自动化 → 腾讯文档」可直接输入 32 位 `space_secret`，保存到本地 vault（0600），不进入知识库数据库。
- **保存即生效**：桥插件监听到 vault 变化后自动重连，无需重启 DSH；支持清除 token。
- **状态可见**：显示已连接工具数、token 指纹和来源；若 `TDOC_OAUTH_ACCESS_TOKEN` 覆盖 vault，会明确提示。
- **安全**：接口只返回指纹，不返回 token 明文；非法长度/字符在写入前拒绝。

## 安装

```bash
dsh plugin --profile web add "github:sibetlyf/dsh-knowledge#v2.15.4"
```
