# 知识库 2.15.6

## 更新

- **早晨卡片与每日待办合并**：工作日报页顶部同一张卡片同时展示早晨简报、工作/生活待办、顺延未完成和复制简报。
- **周报 / 月报**：日报操作栏新增「周报」「月报」，汇总周期内每日日报和待办；默认调用 DSH 当前云端默认模型生成，模型不可用时自动回退到本地汇总，不阻塞查看。
- **云端模型默认**：工作记录没有显式配置模型时，自动使用 `agentDefaultModel` 当前选择；用户仍可在采集设置中覆盖。
- 周报/月报弹窗可复制 Markdown；显示周期范围、是否由云端模型生成以及回退原因。

## 安装

```bash
dsh plugin --profile web add "github:sibetlyf/dsh-knowledge#v2.15.6"
```
