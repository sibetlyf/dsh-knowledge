# 知识库 2.15.8

## 更新

- **欢迎页早晨卡片重做**：按 dsh-daily-report 的卡片样式重排，440px 宽、圆角、官方层级背景与阴影，带指向鲸鱼的小箭头。
- **卡片结构**：标题 + 日期/待办数、昨日回顾摘要、统计行、会议助手高亮、今日待办列表、快捷添加、底部「刷新 / 打开日报」。
- **位置与开合**：卡片自动显示在鲸鱼上方；空间不足时自动翻到下方；支持关闭、Esc、点击外部收起，点击鲸鱼重新打开。
- **会议助手联动**：卡片通过公共工具接口显示「会议助手正在听 / 会议助手 · 会议标题 / 已就绪 / 未连接」，不暴露设备等原始状态。
- 日报页不再承载早晨卡片，保持日报正文与来源核对。

## 安装

```bash
dsh plugin --profile web add "github:sibetlyf/dsh-knowledge#v2.15.8"
```
